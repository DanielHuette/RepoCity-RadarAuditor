# Schrift Archivo

`Archivo-Variable.woff2` ist die variable Schrift Archivo (Achsen Breite und Stärke, lateinischer Zeichensatz mit Umlauten), Quelle: https://github.com/Omnibus-Type/Archivo/releases. Lizenz: SIL Open Font License 1.1, siehe `OFL.txt`.

Die App lädt die Schrift von hier und nicht von Google Fonts: Das Nachladen von Google überträgt die IP-Adresse jedes Besuchers an Google und ist in Deutschland abmahnfähig.
